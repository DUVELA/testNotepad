removeElem {n = Z} value (y :: []) (There later) impossible

만약 이 방식도 실패한다면 오류 메시지를 확인한 뒤, Uninhabited (Elem value []) 구현을 직접 제공할지 검토하면 됩니다.

1. splitListHelp의 두 인자는 역할이 다릅니다
splitListHelp : List a -> (input : List a) -> SplitList input
이 타입을 세 부분으로 나누어 보겠습니다.
- 첫 번째 List a: 재귀를 진행하기 위한 보조 리스트입니다.
- 두 번째 (input : List a): View를 만들어야 하는 실제 입력 리스트입니다.
- SplitList input: 반환값은 두 번째 인자로 받은 리스트의 구조를 설명하는 View여야 합니다.
